## Scenario Description
This console application models a Jeepney Fleet Management System demonstrating core OOP principles in Dart:
- **Class & Constructor:** `Jeepney` class with parameterized constructor.
- **Encapsulation:** Private field `_collectedFare` managed via public methods and getters.
- **List Usage:** A `List<Jeepney>` storing and managing multiple vehicle instances.

## How to Run
1. Open [DartPad](https://dartpad.dev).
2. Copy and paste `bin/oop_exercises.dart`.
3. Click **Run**.
